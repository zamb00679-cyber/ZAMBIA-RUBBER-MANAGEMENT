ZAMBIA RUBBER MANAGEMENT - Android App Project

ဒီ ZIP သည် Android Studio ဖြင့် APK ထုတ်ရန် ပြင်ဆင်ထားသော Project ဖြစ်သည်။ APK ဖိုင်ကိုယ်တိုင် မဟုတ်သေးပါ။

Windows 11 တွင် APK ထုတ်ရန်:
1. Android Studio ကို ဖွင့်ပါ။
2. File > Open ကိုနှိပ်ပြီး ZIP ဖြည်ထားသော ZAMBIA-RUBBER-ANDROID folder ကိုရွေးပါ။
3. Gradle Sync ပြီးအောင်စောင့်ပါ။ Internet လိုအပ်နိုင်သည်။
4. Build > Build Bundle(s) / APK(s) > Build APK(s) ကိုနှိပ်ပါ။
5. Build ပြီးလျှင် app/build/outputs/apk/debug/app-debug.apk ထဲတွင် APK ရှိမည်။
6. APK ကို Android ဖုန်းသို့ကူးပြီး install လုပ်ပါ။

App ID: com.zambia.rubbermanagement
App Name: ZAMBIA RUBBER MANAGEMENT

သတိပြုရန်:
- ဒီ App သည် လက်ရှိ HTML စာမျက်နှာကို Android WebView ထဲတွင် ဖွင့်ပေးသည်။
- စာရင်းဒေတာသည် ဖုန်းတစ်လုံး၏ WebView local storage ထဲတွင်သာ သိမ်းမည်။ ဖုန်းများအကြား အလိုအလျောက် မမျှဝေပါ။
- APK ထုတ်ပြီးနောက် ဖုန်းပေါ်တွင် စာရင်းသိမ်းခြင်း၊ ပုံနှိပ်ခြင်း၊ ဖိုင်ထုတ်/သွင်းခြင်းတို့ကို သီးခြားစမ်းသပ်ပါ။
